# slides-and-shells

Talks I have given, and the code that went with them.

Each directory is one talk. The slides are in there, but so is everything the
talk was actually about, in a state where you can run it rather than just read
about it. If a talk claimed something worked, the thing that makes that claim
true is in the same directory.

| Talk | Venue | Year | |
|---|---|---|---|
| [From Prompt to Payload](prompt-to-payload/README.md) | Tokenmaxxing Village | 2026 | An offensive AI harness that runs entirely on local hardware, with a calibration target for finding out what your model actually gets right. |

## Layout

Each talk directory stands on its own. Clone the repo, go into one, and follow
its README. Nothing at this level is needed to run anything below it.
