# Talk

This repo came out of a talk, *From Prompt to Payload: Harnessing Local Models
for Offensive Work*, given at the Tokenmaxxing Village in 2026.

[`slides/from-prompt-to-payload.pdf`](slides/from-prompt-to-payload.pdf) is the deck.

The talk was 15 minutes plus questions, so it only showed one thing: a local
model reverse-engineering the stripped binary in `lab/re-target/`, scored
against the source that ships beside it. Everything else in this repo is in the
repo rather than in the deck.

Nothing here depends on the talk. If you found this years later and have no
idea what the Tokenmaxxing Village was, start at the top-level README and
ignore this directory.
